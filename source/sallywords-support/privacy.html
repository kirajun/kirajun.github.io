PRIVACY / 隐私说明

学习数据，保存在本地。

更新日期：2026 年 11 月 14 日

1. 图片与 OCR

用户选择或拍摄的单词表图片由设备上的 Apple Vision 框架进行识别。当前版本不设业务服务器，不会向开发者或第三方上传原图、OCR 内容、单词本或练习记录。原图用于当前导入过程，保存单词本时不将原图写入学习数据库。

2. 学习数据

单词本、释义、练习记录、错词和复习进度保存在当前设备的应用沙盒中。应用不提供云同步。系统备份是否包含这些数据取决于你的 iOS 或 iPadOS 备份设置。删除应用可能同时删除这些本地数据。

3. 相机与相册权限

相机权限仅用于用户主动发起的拍照导入，可在系统“设置”中更改授权。相册导入使用系统图片选择器，应用只处理你选定的图片。如果图片原件仅保存在 iCloud，需要先由系统下载到设备，才能离线导入。

4. 账号与分析

当前版本不要求注册账号，不包含广告，也未接入第三方行为分析或用户画像服务。

5. 系统能力

朗读功能使用 Apple 提供的设备端系统语音服务。英文语音资源需事先安装在设备上；缺少资源时，请联网在系统辅助功能设置中下载。语音资源由 iPadOS 或 iOS 管理。图片识别、内置词典查询和学习记录的保存均在本地完成。

6. 保留与删除

学习数据会保留在设备上，直到你删除相应条目、单词本或应用。你可以在应用内删除单词本或其中的单词。已确认的自定义释义还会保存在本地词典缓存中，删除单词本不会同时清除此缓存。删除应用会移除其本地沙盒数据；系统“卸载 App”可能保留文稿与数据。设备备份中的副本由你通过系统备份设置管理。

7. 后续变更

若未来增加云同步、在线释义或账号功能，SallyWords 会在启用相关能力前更新本说明，并明确告知数据用途。

8. 支持来信与本网站

你主动发送的支持邮件可能包含邮箱地址、设备信息及问题描述，我们仅将这些信息用于回复和排查你反馈的问题。请避免提交无关的个人资料；如需删除来信中的个人信息，可通过下方邮箱联系。

本网站没有广告、分析脚本或收集信息的表单。本网站托管于 GitHub Pages。GitHub 会为了安全目的记录并保存访问者的 IP 地址；这些网站访问记录与应用内本地学习数据相互独立。详情见 GitHub Pages 数据处理说明。
