賽博小帳篷支援

更新日期：2026年11月18日。

賽博小帳篷提供全螢幕名字牌、狀態牌、專注計時、QR Code 展示、輕提詞、氛圍桌面和擲杯小儀式。面向 iPhone，安裝要求為 iOS 17 或以上；本次發布驗證涵蓋 iOS 27。待機顯示由 iPhone 系統管理。

如何切換成狀態牌？

進入「桌牌」，選擇狀態卡片後全螢幕展示。也可在展示畫面點「切換場景」選擇另一張卡片。進行中的專注計時會繼續。

如何在待機中加入？

先在卡片編輯中允許文字公開。Duo 進入待機後長按鐘面並解鎖，選擇「模塊」→「自定義」→ 小工具區域，再選擇「賽博小帳篷」。其他 iPhone 按系統要求連接充電器、橫向靜置並鎖定螢幕，在待機的小工具頁長按加入。App 內「設定 → 把小帳篷放進待機」提供引導。顯示尺寸和更新由系統管理。

QR Code 為什麼不顯示？

編輯 QR Code 或社交卡，同時開啟「允許待機小工具顯示文字」與「同時顯示 QR Code」，儲存並選取。僅匯入圖片不會自動授權鎖定螢幕公開。待機夜間顏色和亮度可能影響掃碼，可在 App 中開啟全螢幕展示並保留白邊。

如何立即隱藏待機內容？

關閉卡片公開開關會更新共享快照，但系統可能暫留舊畫面。需要立即隱藏時，從主畫面或待機畫面移除小工具。

QR Code 裁切後能恢復原圖嗎？

原始圖片沒有被修改。重新裁切以目前儲存的圖片為基礎；如需找回先前裁去的區域，請重新匯入來源圖片。

為什麼沒有結束提醒？

檢查「設定 → 專注結束時提醒」和系統通知權限。專注模式、靜音及系統設定可能影響提醒呈現；請同時檢查實際計時狀態。

資料在哪裡？

內容儲存在本機，沒有帳號或 App 自有雲端同步。裝置備份由系統設定決定。排查故障時優先更新安裝，不要先解除安裝，以免遺失本機內容。

如何查看隱私政策？

在 App「設定 → 隱私政策」可離線閱讀完整政策，也可開啟本網站的隱私政策頁。

全螢幕按鈕消失了怎麼辦？

預設 5 秒無操作後收起控制，輕點畫面或右下角省略號找回。設定中可關閉自動隱藏。開啟防誤觸後，解鎖提示平時隱藏，觸碰螢幕時短暫顯示；長按螢幕約 2 秒解除；VoiceOver 提供「解除防誤觸」按鈕。單張全螢幕是預設版面，只有開啟「記住展示佈局」後才儲存主動選擇的雙向版面。

如何管理桌牌？

長按桌牌收藏，或進入「管理」收藏與拖動排序。收藏排在前面，桌牌頁和全螢幕切換共用順序。「最近展示」僅紀錄實際進入全螢幕的桌牌。

如何備份和恢復？

設定 → 備份與恢復，可匯出完整 .duotentbackup 檔案或選擇檔案預覽。合併會加入桌牌、專注和擲杯歷史，保留現有講稿、計時與設定；取代還原全部內容。還原前自動儲存本機還原副本，可再次開啟預覽。匯入的桌牌不自動公開。備份內的執行中的計時在取代時暫停，需手動繼續；提醒關閉。

節能選項

低電量模式或電量低於 20% 時減少寵物持續動畫，也可手動開啟。可設定全螢幕無操作後調暗，觸碰、離開或進入背景恢復亮度；使用者手動調整亮度後，會保留你的選擇。不承諾固定節電幅度。

獨立小工具與備份

長按已加入的小工具並編輯，可選擇跟隨目前、固定某張公開桌牌或專注狀態。固定桌牌不受 App 切換工具影響。Logo 需要另行授權。小工具選擇由 iOS 管理，App 備份儲存桌牌、ID、排版與圖片，但不匯出或自動恢復系統小工具位置與配置；還原後請重新檢查每個小工具的卡片選擇與公開授權。

祝福擺拍

在「新建」中選擇生日、咖啡或禮物模板，改寫祝福與落款後儲存。打開全螢幕，擺在真實場景裡與蛋糕、咖啡、禮物一起拍照。

專注與休息

打開「工具 → 專注計時」，可選1–120分鐘專注、1–60分鐘休息，每1–8段專注後長休息。預設每段結束後由你選擇下一步；可選自動銜接，在本輪長休息結束後停止。連續流程即使關閉 App也按儲存時間推進，不希望離開期間計數時請勿開啟。暫停時間不計入專注；提前結束單獨留存，不計入完成次數。統計按本機日曆的結束日期歸屬，不含休息或提前結束時長。近期列表顯示30條，備份保留最近最多 10,000 筆。可在近期紀錄中清空歷史，不影響正在執行的計時。

開始前可選擇結束後返回的桌牌；若過程中主動換了場景，結束時保留該場景，需要時點「返回原來的桌牌」。原桌牌已刪除時回到目前可用桌牌。切換桌牌、貓狗或關閉寵物均不會重置計時。

「寵物陪伴專注」沿用氛圍桌面的貓狗與顯示開關。開啟後專注時安靜、暫停時舒展、完成時顯示開心姿態；輕點回應優先，3秒後回到目前狀態。關閉聯動後恢復固定或自動表情設定。重新開啟已完成的專注流程不會重播慶祝。

通知和待機小工具按同一套有限時間表推算，暫停、繼續和結束會替換待發提醒，實際送達及小工具更新仍由系統決定。替換備份會按備份時間暫停流程並關閉提醒、專注共享；合併保留目前計時，對專注歷史按紀錄識別碼排除重複項目。

專注即時動態（App 內「專注實時活動」）

在工具 → 專注計時中開啟「專注實時活動」，查看通用階段與倒數計時，不含個人桌牌內容。App 內暫停、繼續和結束會更新即時動態。移除後不會反覆彈回，可點「重新顯示實時活動」或主動開始下一階段；系統拒絕或結束活動不影響本機計時。倒數計時由系統按結束時間顯示，不需要每秒執行背景工作。App 暫停執行期間階段到點，會提示本段結束並請你打開 App 同步；自動流程與本機提醒仍按儲存的時間繼續。展示位置、可用性和持續時長由系統決定，不承諾自動佔據整個待機螢幕。

快捷啓動

在設定 → 快捷啓動開啟系統「捷徑」App，搜尋「賽博小帳篷」（英文系統下為 CyberTent）。可選「展示指定桌牌」「開始指定時長專注」「打開寵物桌面」，並修改桌牌與分鐘參數。操作要求解鎖並開啟 App；已有流程時打開原流程，不重置計時，包括暫停和已完成階段。先結束原流程，再開始其他時長。卡片刪除後需重新選擇；寵物入口顯示已選夥伴，不重置專注。系統捷徑與即時動態權限不包含在 App 備份中。

多篇講稿與快速暫停

在工具 → 輕提詞中新建講稿，使用每篇右側選單重新命名（編輯標題）、複製或刪除。每篇分別儲存字級、速度、鏡像、醒目顯示、開場倒數計時與文字閱讀位置。至少保留一篇。全螢幕輕點內文、點常駐暫停按鈕或按外接鍵盤空白鍵，即可暫停或繼續；段落列表可快速跳轉。切到背景、切換場景、改變寬度或開啟防誤觸會暫停。內文修改後從頭閱讀，僅改標題或字級會保留位置；開場倒數只在從頭播放時使用。精簡的半透明控制列讓講稿有更多顯示空間；點速度數字即可在小型彈出視窗調速，開啟時會暫停，關閉後需手動繼續。系統啟用「降低透明度」時改用實色背景。

寵物個性化

氛圍桌面支援為貓狗分別起名、選擇三種毛色、圍巾或蝴蝶結與小動作。貓狗採用不同活動節奏。減少動態效果或節能時停止自動變化、保留靜態姿態；專注聯動與觸碰回應優先於固定姿態。

分享桌牌模板

桌牌預覽右上角或長按桌牌可開啟分享。預設保留樣式、替換成虛構範例；標題、單位、落款、QR Code 文字、QR Code 圖片和 Logo 等逐項勾選後才會帶入。先核對預覽及文字，再匯出 .duotenttemplate 檔案或1600×900預覽圖；可在系統檔案 App 中繼續分享。桌牌列表下方「匯入桌牌模板」可預覽並加入，不覆蓋現有卡片、計時或講稿，也不自動開啟待機公開。同一模板重複匯入會得到不同卡片。

語言與備份範圍

支援簡體中文、繁體中文與英文，語言跟隨系統對本 App 的選擇；不改寫任何已儲存內容。完整備份包含全部講稿、閱讀位置、兩種寵物的名字與外觀。取代還原這些內容，合併仍保留本機講稿與設定。語言選擇由 iOS 管理，與通知、即時動態等系統設定一樣，不由備份覆蓋。
