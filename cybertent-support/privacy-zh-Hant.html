賽博小帳篷隱私政策

我們如何處理內容

賽博小帳篷不要求註冊帳號，不含廣告、統計分析、追蹤 SDK 或自有雲端服務。App 不會將卡片、圖片、講稿、專注狀態、專注紀錄和擲杯紀錄上傳給開發者或第三方伺服器。

卡片、顯示設定、講稿、專注狀態、最近最多 10,000 筆專注紀錄及最近 30 次擲杯紀錄儲存在裝置上。App 透過系統照片或檔案選擇器讀取你主動選擇的圖片，不瀏覽整個照片圖庫，不要求相機、麥克風、通訊錄或定位權限。QR Code 匯入在本機辨識位置、校正方向並讓你確認裁切；Logo 匯入在本機校正方向。儲存處理後的 PNG，不修改原始圖片，也不複製原圖的定位等中繼資料。為控制記憶體用量，處理尺寸最長邊不超過 4,096 像素。取消裁切不會替換原本的圖片。

公開展示和小工具

所有你允許公開的卡片文字及其固定識別碼、允許展示的專注狀態，以及切到擲杯場景時的目前結果，可以寫入本機共用容器，供本 App的小工具讀取。講稿與專注歷史不會寫入該快照。

QR Code 預設不共享。只有同時開啟文字公開和「同時顯示 QR Code」，儲存該卡片後，App 才將已授權的 QR Code 製作成帶白邊的 600×600 預覽圖，與公開文字一起儲存在本機共用容器。原始檔案和 QR Code 原始字串不直接複製，但預覽圖仍可掃描並讀出相同資訊。鎖定螢幕畫面可能被周圍的人看到或掃描，請只公開你願意展示的內容。

Logo 同樣預設不共享，需單獨開啟 Logo 共享，才會產生最長邊不超過 240 像素的預覽。每個小工具可以跟隨目前展示、固定公開桌牌或顯示專注。固定桌牌不受 App 切換卡片或工具影響；關閉授權或刪除卡片後，下次讀取公開索引時會隱藏相應內容。系統可能暫時保留已渲染的小工具畫面；若需要立即隱藏，應從主畫面或待機畫面移除小工具。QR Code 中的網址不會被本 App自動開啟。

通知與權限

僅在你啟用專注與休息結束提醒時請求通知權限，用於本機到點提醒。你可在 App 內關閉提醒，也可在系統設定中取消通知權限。不允許通知不影響其他功能。

保留、刪除和備份

你可以編輯或刪除卡片、替換圖片、編輯或清空講稿、清空專注或擲杯歷史、關閉公開展示。刪除卡片或儲存圖片變更後，App 會清理不再使用的匯入檔案；取消編輯或異常中斷遺留的未使用檔案，最遲在下次成功載入時清理。解除安裝 App 會刪除相應本機 App 資料；系統小工具快取、裝置備份的保留與移除由系統管理。系統備份可能包含本機內容，具體取決於你的裝置備份設定。你可以主動匯出完整備份至系統檔案選擇器中的位置。備份包含卡片、圖片、講稿、設定和本機歷史，未加密，請妥善保管。所選檔案供應商可能依其設定同步內容；App 不會自動上傳備份。還原前在 App 私有目錄保留一份還原副本，下次還原時覆蓋，解除安裝時隨 App 資料刪除。匯入的桌牌關閉公開、QR Code 及 Logo 共享；取代還原會關閉提醒，並暫停備份中仍在執行的計時。App 沒有自有雲端同步。

主動聯絡支援

意見回饋入口僅產生可編輯郵件草稿，預填 App 版本、Build、系統版本和裝置類型；不附帶卡片、圖片或講稿，也不會自動傳送。未設定系統郵件時，可主動複製信箱和意見回饋資訊。

如你透過信箱聯絡我們，我們會收到你主動傳送的電子郵件地址、內文和附件，僅用於處理意見回饋和回覆。請勿傳送密碼或私人 QR Code 等無關資訊。你可透過同一電子郵件地址提出刪除支援郵件中個人資訊的請求；App 的本機內容由你在裝置上管理，開發者無法遠端讀取或刪除。

政策更新

如未來功能或資料處理方式改變，我們會同步更新本政策與商店隱私說明。有關個人資訊處理的問題請聯絡 kirajun@gmail.com。

支援網站

本支援網站提供靜態政策與說明頁面，不設定廣告、分析腳本或聯絡表單。瀏覽網頁時，網站代管服務會處理提供頁面所需的一般網路請求資訊，例如 IP 位址；這與離線 App 內的內容處理相互獨立。

即時動態與捷徑

專注即時動態預設關閉。開啟後，僅將計時階段、時間和內部流程識別碼交給系統，在支援的鎖定螢幕與動態島展示；不包含桌牌名稱、文字、QR Code、Logo、講稿或歷史紀錄。旁人可能看到計時。可在 App 或系統設定中關閉。即時動態開關與識別碼屬於目前裝置，不匯出到 App 備份；還原備份後會關閉此功能。

捷徑可列出本機桌牌名稱和識別碼，供你主動選擇桌牌。三個操作均要求解鎖並開啟 App，不自動授予待機公開權限。Apple 儲存或同步捷徑的方式由系統設定決定，CyberTent 不提供捷徑或 Siri 伺服器，也不會將私人桌牌自動索引到Spotlight。

個性化、講稿與模板分享

寵物名字、毛色、配件、多篇講稿的內容與閱讀位置僅儲存在本機私有資料及你主動匯出的完整備份中，不寫入公開小工具索引。語言由系統設定管理，切換語言不會翻譯已儲存的內容。

模板分享由你主動操作，預設使用虛構範例。只有逐項選入的個人文字、QR Code 內容、圖片或 Logo 才會進入匯出檔案；匯出前提供預覽。模板檔案可再次編輯，預覽圖片用於分享畫面；兩者均不包含其他卡片、講稿或專注歷史。匯入模板會新建卡片，預設關閉公開共享。透過檔案選擇器選擇的服務可能依其設定同步或分享匯出內容；App 不會自動傳送給任何人。

匯入模板內的圖片保留檔案內容及其可能攜帶的中繼資料，不再執行前述照片匯入時的移除中繼資料處理。請僅選入你願意分享的圖片。
